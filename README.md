# Home Grocery & Meal Planner

A 4-page offline web app (no installation, no server needed).

Pages: `index.html` (Home), `grocery.html` (206 items, prices, Buy checkbox, total), `meals.html` (50 recipes), `summary.html` (cart, totals, print, CSV).

## Use on your PC
Unzip the folder and double-click `index.html`.

## Put it on GitHub (and get a free website)
1. Sign in at github.com and click **New repository** (name it e.g. `grocery-app`, set Public).
2. Click **uploading an existing file**, drag in ALL files from this folder (not the zip), then **Commit changes**.
3. Go to **Settings > Pages**, under Branch choose `main` and `/ (root)`, then **Save**.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/grocery-app/`.

Prices are USD estimates (only UHT milk comes from a Carrefour Lebanon listing). Edit them inside the app; they are saved in your browser.
